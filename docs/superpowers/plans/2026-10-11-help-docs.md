# Справка в портале — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Страница «Справка» в портале: оглавление и статья, две аудитории, статьи — Markdown-файлы в `backend/help/`.

**Architecture:** Бэкенд читает каталог `backend/help/` (разделы из `sections.js`, статьи из `.md` с шапкой), фильтрует по аудитории читателя и включённым модулям и отдаёт двумя маршрутами плюс маршрут картинок. Фронтенд — две ленивые страницы на существующих примитивах (`Segmented`, `SearchBar`, `Crumbs`, `AnchorRail`, `MarkdownViewer`). Ссылка в подвале появляется по флагу `hasHelp` из `/api/me`.

**Tech Stack:** Node 24 (CommonJS, `module-alias`, `node:test`), Express, React 19 + React Router 7 (data router), Tailwind v4, Toast UI Viewer.

**Spec:** `docs/superpowers/specs/2026-10-11-help-docs-design.md`. Макет: `.superpowers/sdd/2026-10-11-help-docs/mockup.html` — код фронтенда повторяет его.

## Global Constraints

- Git ведёт владелец: **никаких `git add`/`commit`/`push`**. Шаги «Commit» отсутствуют намеренно.
- Менеджер пакетов — pnpm; новых зависимостей не добавляем.
- Тесты: `node --test <файл>` только по файлам справки; полный `pnpm test` бэкенда не запускать.
- Фронтенд: иконки только `react-icons/ri`; без произвольных `text-[Npx]`; размеры в rem/утилитах; `eslint-disable react-hooks/*` не писать (плагина нет).
- Тексты интерфейса на русском, название страницы и ссылки — «Справка».
- Чужая аудитория, скрытый раздел, неизвестная статья или картинка — всегда 404 без различия причин.
- Имена разделов, статей: `^[a-z0-9]+(?:-[a-z0-9]+)*$`; картинок: `^[a-z0-9][a-z0-9._-]*\.(png|jpe?g|webp|gif)$` (без учёта регистра).
- Статей в поставке нет: `backend/help/` содержит только `sections.js`.
- Проверку в браузере (playwright) не запускать: интерфейс смотрит владелец.

## Review Focus

1. Клиент запрашивает сотрудническую статью или картинку прямым адресом → 404 (тест в Task 2 на `findArticle`, в Task 3 — проверка в контроллере картинок через тот же `findSection`).
2. Параметр пути с `..`, `/`, `%2e` → 404, файл вне `backend/help/` не читается (тест в Task 2: `findArticle` с негодными именами; Task 3: шаблон имени картинки).
3. Файл статьи с битой шапкой (нет закрывающей `---`, нет `title`) → статья пропущена, остальные работают (тест в Task 2).
4. Раздел упомянут в каталоге, но папки нет / папка есть, но раздела нет в `sections.js` → не падаем, статья-сирота пропущена с предупреждением (тест в Task 2).
5. В статье меньше трёх `h2` или их нет → рейки нет, вёрстка одной колонкой (Task 6, чистая функция `railSections` с тестом).

```js
/**
 * Шапка статьи справки: плоские пары `ключ: значение` между строками `---`.
 * Свой разборщик вместо YAML-библиотеки: вложенности и типов в шапке нет, а
 * зависимость ради пяти строк не нужна.
 */
const strip = (value) => {
  const trimmed = value.trim();
  const quoted = /^(["'])(.*)\1$/.exec(trimmed);
  return quoted ? quoted[2] : trimmed;
};

const parseFrontMatter = (text) => {
  const lines = String(text || "")
    .replace(/^﻿/, "")
    .split(/\r?\n/);
  if (lines[0]?.trim() !== "---") return null;

  const end = lines.findIndex((line, index) => index > 0 && line.trim() === "---");
  if (end === -1) return null;

  const meta = {};
  for (const line of lines.slice(1, end)) {
    if (line.trim().startsWith("#")) continue;
    const colon = line.indexOf(":");
    if (colon <= 0) continue;
    meta[line.slice(0, colon).trim()] = strip(line.slice(colon + 1));
  }

  return { meta, body: lines.slice(end + 1).join("\n").trim() };
};

module.exports = { parseFrontMatter };
```

- [ ] **Step 5: `catalogue.js`**

```js
const fs = require("node:fs");
const path = require("node:path");

const { parseFrontMatter } = require("./frontMatter");

/**
 * Каталог справки: разделы из help/sections.js, статьи — файлы
 * help/<аудитория>/<раздел>/<статья>.md. Негодный файл не роняет справку:
 * он пропускается, а причина уходит в предупреждения.
 */
const HELP_ROOT = path.resolve(__dirname, "../../help");
const NAME = /^[a-z0-9]+(?:-[a-z0-9]+)*$/;
const DATE = /^\d{4}-\d{2}-\d{2}$/;
// Ссылка только внутрь портала: «/путь», но не «//хост»
const INTERNAL_LINK = /^\/(?!\/)/;

const readArticle = (file, slug) => {
  const parsed = parseFrontMatter(fs.readFileSync(file, "utf8"));
  if (!parsed) return { error: "нет шапки" };
  const { meta, body } = parsed;
  if (!meta.title || !meta.summary) return { error: "нет title или summary" };

  const order = Number(meta.order);
  const linked = INTERNAL_LINK.test(meta.link || "") && Boolean(meta.linkLabel);
  return {
    article: {
      slug,
      title: meta.title,
      summary: meta.summary,
      order: meta.order !== undefined && Number.isFinite(order) ? order : null,
      updated: DATE.test(meta.updated || "") ? meta.updated : null,
      link: linked ? meta.link : null,
      linkLabel: linked ? meta.linkLabel : null,
      body,
    },
  };
};

const byOrder = (a, b) => {
  if (a.order !== null && b.order !== null) return a.order - b.order;
  if (a.order !== null) return -1;
  if (b.order !== null) return 1;
  return a.title.localeCompare(b.title, "ru");
};

const listDir = (dir) => {
  try {
    return fs.readdirSync(dir, { withFileTypes: true });
  } catch {
    return [];
  }
};

const loadCatalogue = (root, defs) => {
  const warnings = [];
  const sections = defs.map((def) => ({ ...def, articles: [] }));
  const find = (audience, key) =>
    sections.find((s) => s.audience === audience && s.key === key);

  for (const audience of ["client", "staff"]) {
    for (const dir of listDir(path.join(root, audience))) {
      if (!dir.isDirectory()) continue;
      const section = find(audience, dir.name);
      for (const entry of listDir(path.join(root, audience, dir.name))) {
        if (!entry.isFile() || !entry.name.endsWith(".md")) continue;
        const where = `${audience}/${dir.name}/${entry.name}`;
        const slug = entry.name.slice(0, -3);
        if (!section) {
          warnings.push(`${where}: раздела нет в sections.js`);
          continue;
        }
        if (!NAME.test(slug)) {
          warnings.push(`${where}: имя файла — латиница, цифры, дефис`);
          continue;
        }
        const { article, error } = readArticle(
          path.join(root, audience, dir.name, entry.name),
          slug,
        );
        if (error) warnings.push(`${where}: ${error}`);
        else section.articles.push(article);
      }
    }
  }

  for (const section of sections) section.articles.sort(byOrder);
  return { sections, warnings };
};

let cached = null;
const getCatalogue = () => {
  if (cached) return cached;
  const catalogue = loadCatalogue(HELP_ROOT, require("../../help/sections"));
  for (const warning of catalogue.warnings) {
    console.warn(`[help] ${warning}`);
  }
  // Вне прода читаем каждый раз: правка файла статьи видна без перезапуска
  if (process.env.NODE_ENV === "production") cached = catalogue;
  return catalogue;
};

module.exports = { HELP_ROOT, NAME, loadCatalogue, getCatalogue };
```

- [ ] **Step 6: `visibility.js`**

```js
/**
 * Кто что видит в справке. Чистые функции: читатель — это
 * `{ isEndUser, modules }`, где modules — Preferences.modules.
 * Клиент видит только клиентскую часть, сотрудник — обе.
 */
const audiencesFor = (isEndUser) => (isEndUser ? ["client"] : ["staff", "client"]);

const moduleOpen = (section, modules) =>
  !section.modules?.length ||
  section.modules.some((key) => Boolean(modules?.[key]?.isActive));

const visibleSections = (sections, { isEndUser, modules }) => {
  const audiences = audiencesFor(isEndUser);
  return sections.filter(
    (section) =>
      audiences.includes(section.audience) &&
      section.articles.length > 0 &&
      moduleOpen(section, modules),
  );
};

const hasHelp = (sections, reader) => visibleSections(sections, reader).length > 0;

const findSection = (sections, reader, audience, key) =>
  visibleSections(sections, reader).find(
    (section) => section.audience === audience && section.key === key,
  ) || null;

const findArticle = (sections, reader, audience, key, slug) => {
  const section = findSection(sections, reader, audience, key);
  const article = section?.articles.find((item) => item.slug === slug);
  return article ? { section, article } : null;
};

module.exports = { audiencesFor, visibleSections, hasHelp, findSection, findArticle };
```

```js
const { AppError } = require("@/middleware/errorHandling");
const { getCatalogue, HELP_ROOT } = require("@/services/help/catalogue");
const {
  audiencesFor,
  visibleSections,
  findSection,
  findArticle,
} = require("@/services/help/visibility");

/**
 * Справка портала (docs/help.md). Статьи — файлы в backend/help; что из них
 * видит читатель, решает services/help/visibility. Любой отказ — 404 без
 * причины: клиенту незачем знать, что сотрудническая статья существует.
 */
const IMAGE = /^[a-z0-9][a-z0-9._-]*\.(png|jpe?g|webp|gif)$/i;

const readerOf = async (req) => {
  const preferences = await Preferences.findOne({}).select("modules").lean();
  return {
    isEndUser: req.auth.isEndUser,
    modules: preferences?.modules || {},
  };
};

const notFound = () => new AppError("Страница справки не найдена", 404);

exports.index = async (req, res, next) => {
  try {
    const reader = await readerOf(req);
    const sections = visibleSections(getCatalogue().sections, reader);
    const audiences = audiencesFor(reader.isEndUser)
      .map((key) => ({
        key,
        sections: sections
          .filter((section) => section.audience === key)
          .map((section) => ({
            key: section.key,
            title: section.title,
            articles: section.articles.map(({ slug, title, summary }) => ({
              slug,
              title,
              summary,
            })),
          })),
      }))
      .filter((audience) => audience.sections.length > 0);
    res.status(200).json({ audiences });
  } catch (error) {
    next(new AppError("Не удалось загрузить справку", 500, true, error));
  }
};

exports.article = async (req, res, next) => {
  try {
    const { audience, section: key, slug } = req.params;
    const found = findArticle(
      getCatalogue().sections,
      await readerOf(req),
      audience,
      key,
      slug,
    );
    if (!found) return next(notFound());

    const { section, article } = found;
    res.status(200).json({
      audience,
      slug: article.slug,
      title: article.title,
      summary: article.summary,
      updated: article.updated,
      link: article.link,
      linkLabel: article.linkLabel,
      body: article.body,
      section: { key: section.key, title: section.title },
      siblings: section.articles
        .filter((item) => item.slug !== article.slug)
        .map(({ slug: sibling, title }) => ({ slug: sibling, title })),
    });
  } catch (error) {
    next(new AppError("Не удалось загрузить статью", 500, true, error));
  }
};

exports.image = async (req, res, next) => {
  try {
    const { audience, section: key, file } = req.params;
    const section = findSection(
      getCatalogue().sections,
      await readerOf(req),
      audience,
      key,
    );
    if (!section || !IMAGE.test(file)) return next(notFound());

    res.set("X-Content-Type-Options", "nosniff");
    res.sendFile(
      file,
      { root: path.join(HELP_ROOT, audience, key, "img"), dotfiles: "deny" },
      (error) => {
        if (error && !res.headersSent) next(notFound());
      },
    );
  } catch (error) {
    next(new AppError("Не удалось загрузить картинку", 500, true, error));
  }
};
```

```js
// Чистые функции справки (pages/Help): поиск по оглавлению, адреса, рейка.

/** Поиск по названию и аннотации; порядок — как в оглавлении. */
export const searchArticles = (sections, query) => {
  const needle = String(query || "").trim().toLowerCase();
  if (!needle) return [];
  return sections.flatMap((section) =>
    section.articles
      .filter((article) =>
        `${article.title}\n${article.summary}`.toLowerCase().includes(needle),
      )
      .map((article) => ({
        ...article,
        section: { key: section.key, title: section.title },
      })),
  );
};

/** Картинки статьи лежат рядом с ней: `img/файл` → адрес маршрута справки. */
export const resolveImages = (body, base) =>
  String(body || "").replace(
    /(!\[[^\]]*\]\()(img\/[A-Za-z0-9][A-Za-z0-9._-]*)/g,
    (match, open, file) => `${open}${base}/${file}`,
  );

/** Рейка «На этой странице» появляется от трёх заголовков. */
export const railSections = (headings) =>
  headings.length < 3
    ? []
    : headings.map((label, index) => ({ id: `h-${index + 1}`, label }));

export const articlePath = (audience, section, slug) =>
  `/help/${audience}/${section}/${slug}`;

/** Клиентскую часть сотрудник открывает с `?for=client`; клиенту параметр не нужен. */
export const indexPath = (audience, isEndUser, sectionKey) =>
  `/help${!isEndUser && audience === "client" ? "?for=client" : ""}${
    sectionKey ? `#${sectionKey}` : ""
  }`;

const UPDATED = new Intl.DateTimeFormat("ru", {
  day: "numeric",
  month: "long",
  year: "numeric",
});

/** Дата из шапки статьи (ГГГГ-ММ-ДД) словами. Календарная, без пояса. */
export const formatUpdated = (iso) =>
  UPDATED.format(new Date(`${iso}T00:00:00`)).replace(/\s*г\.$/, "");
```

```jsx
import { useCallback, useState } from "react";
import { Link, useLoaderData } from "react-router";
import { BrowserView } from "react-device-detect";
import { RiExternalLinkLine } from "react-icons/ri";
import { toast } from "sonner";

import AnchorRail from "@/components/app/AnchorRail";
import Crumbs from "@/components/app/Crumbs";
import { Button } from "@/components/ui/button";
import { setDocTitle } from "@/hooks/use-doc-title";
import { useAuthedUser } from "@/store/authed-user";
import {
  articlePath,
  formatUpdated,
  indexPath,
  railSections,
  resolveImages,
} from "@/util/help";

import MarkdownViewer from "../../UI/MarkdownViewer";

export async function loader({ params }) {
  const { audience, section, slug } = params;
  const response = await fetch(
    `${import.meta.env.VITE_API_ADDRESS}/api/help/${audience}/${section}/${slug}`,
  );
  if (!response.ok) throw response;
  const article = await response.json();
  setDocTitle(article.title);
  return article;
}

const HelpArticle = () => {
  const article = useLoaderData();
  const { isEndUser } = useAuthedUser();
  const [rail, setRail] = useState([]);

  const { audience, section } = article;
  const body = resolveImages(
    article.body,
    `${import.meta.env.VITE_API_ADDRESS}/api/help/${audience}/${section.key}`,
  );

  // Toast UI якорей заголовкам не ставит: проставляем сами и собираем рейку
  const onRendered = useCallback((element) => {
    const headings = [...element.querySelectorAll("h2")];
    const sections = railSections(headings.map((h) => h.textContent.trim()));
    sections.forEach((item, index) => {
      headings[index].id = item.id;
    });
    setRail(sections);
  }, []);

  const copyLink = async () => {
    try {
      await navigator.clipboard.writeText(window.location.href);
      toast.success("Ссылка скопирована");
    } catch {
      toast.error("Не удалось скопировать ссылку");
    }
  };

  return (
    <div className="mx-auto flex w-full max-w-4xl flex-col gap-5">
      <Crumbs
        section="help"
        chain={[{ label: section.title, to: indexPath(audience, isEndUser, section.key) }]}
      />

      {!isEndUser && audience === "client" && (
        <div className="flex flex-wrap items-center gap-x-3 gap-y-1 rounded-lg border border-border bg-muted px-3 py-2 text-muted-foreground">
          <span>Статья для клиентов</span>
          <button
            type="button"
            onClick={copyLink}
            className="cursor-pointer border-0 bg-transparent p-0 text-inherit underline decoration-border underline-offset-4"
          >
            Скопировать ссылку
          </button>
        </div>
      )}

      <header className="flex flex-col gap-3 sm:flex-row sm:items-start sm:justify-between sm:gap-6">
        <div className="flex min-w-0 flex-col gap-2">
          <h1 className="my-0 text-2xl font-semibold tracking-tight text-balance">{article.title}</h1>
          <p className="my-0 max-w-prose text-base leading-relaxed text-muted-foreground">{article.summary}</p>
          {article.updated && (
            <span className="text-faint">Обновлено {formatUpdated(article.updated)}</span>
          )}
        </div>
        {article.link && (
          <Button asChild variant="outline" className="flex-none self-start">
            <Link to={article.link} className="no-underline">
              <RiExternalLinkLine size={16} aria-hidden />
              {article.linkLabel}
            </Link>
          </Button>
        )}
      </header>

      <div className="flex items-start gap-7">
        <BrowserView renderWithFragment>
          <AnchorRail sections={rail} ariaLabel="На этой странице" className="border-r border-rule pr-4" />
        </BrowserView>
        <div className="min-w-0 flex-1">
          <div className="md-doc help-doc text-base leading-relaxed">
            <MarkdownViewer value={body} onRendered={onRendered} />
          </div>

          {article.siblings.length > 0 && (
            <nav aria-label="Дальше в разделе" className="mt-8 flex flex-col border-t border-rule pt-4">
              <span className="pb-1.5 text-xs font-bold tracking-wider text-faint uppercase">Дальше в разделе</span>
              {article.siblings.map((sibling) => (
                <Link
                  key={sibling.slug}
                  to={articlePath(audience, section.key, sibling.slug)}
                  className="py-1.5 text-foreground-soft no-underline hover:text-accent-text"
                >
                  {sibling.title}
                </Link>
              ))}
            </nav>
          )}
        </div>
      </div>
    </div>
  );
};

export default HelpArticle;
```

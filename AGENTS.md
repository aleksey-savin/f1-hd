# Обязательная проверка документации

При анализе каждой задачи сначала найдите и прочитайте относящуюся к ней документацию проекта и сравните существующие реализации. Не начинайте проектирование или изменение кода, опираясь только на предположения.

Для любых изменений интерфейса обязательно прочитайте соответствующие разделы `docs/ux-ui-guide.md`, проверьте аналогичные страницы приложения и используйте общие компоненты и принятые названия действий. Перед структурной переработкой интерфейса подготовьте мокап; учитывайте уже согласованные с пользователем мокапы.

Это постоянное требование пользователя. Передавая работу другим агентам, включайте его в задание и проверяйте соблюдение при ревью.

Настройки модулей размещаются только отдельными разделами глобальных «Настроек
системы» (`/preferences#<раздел>`). На страницах отчётов, списков и карточек нельзя
добавлять собственное меню «Настройки» или отдельную страницу конфигурации модуля.
Старые адреса настроек могут только перенаправлять в глобальный раздел.

## Проверяемые правила интерфейса и доступа

| Правило | Чем проверяется |
| --- | --- |
| Настройки модулей находятся только в глобальных настройках, без отдельных страниц и меню | `frontend/eslint.config.mjs`: `no-restricted-syntax`; `src/util/design-system.test.js` |
| Даты и периоды вводятся общими `DateField` / `DateRangeField` / `DateTimeField`, без нативного календаря | `frontend/eslint.config.mjs`: `no-restricted-syntax`; `src/util/design-system.test.js` |
| Меню и маршрут отчёта такси используют одно требование доступа; API проверяет его независимо | `TAXI_REPORT_ACCESS`, тест меню, `controllers/taxi.test.js` |
| Новые права такси доступны административным ролям при обновлении; пропущенная старая раздача исправляется новой миграцией | `grantTaxiPermissions.test.js`, `migrate.test.js`, `ci/tests/deploy_migrations.sh` |
| Удалённые поездки сохраняют ключ импорта и исключаются из отчёта, расходов, синхронизации присутствия и ночного сохранения статуса | `controllers/taxi.test.js`, `services/taxi/sync.test.js`, `services/taxi/destination-import.test.js`, `services/workStatusReset.test.js` |
| Варианты заявок при распределении такси ограничены компанией и ответственным пассажиром; сохраняется скоуп доступа | `controllers/taxi.test.js`, `components/Taxi/allocation-state.test.js` |
| Заказы такси оформляются только в Яндексе или внешнем приложении; интеграция HD не создаёт и не отменяет заказы | `services/taxi/provider.test.js`, `controllers/taxi.test.js`; разрешённые методы ограничены в `services/taxi/provider.js` |

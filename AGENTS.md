# Обязательная проверка документации

При анализе каждой задачи сначала найдите и прочитайте относящуюся к ней документацию проекта и сравните существующие реализации. Не начинайте проектирование или изменение кода, опираясь только на предположения.

Для любых изменений интерфейса обязательно прочитайте соответствующие разделы `docs/ux-ui-guide.md`, проверьте аналогичные страницы приложения и используйте общие компоненты и принятые названия действий. Перед структурной переработкой интерфейса подготовьте мокап; учитывайте уже согласованные с пользователем мокапы.

Это постоянное требование пользователя. Передавая работу другим агентам, включайте его в задание и проверяйте соблюдение при ревью.
